# MWM Les

A 3D reading adventure for Norwegian children aged 4 to 7. Children sail between islands with a companion and bring colour back to each island by learning the sounds of the letters. Every instruction is spoken (bokmål); written text arrives only after the child can read it.

Built with Godot 4.6 for Android. No ads, no tracking, no internet permission.

- Game design: [docs/GDD.md](docs/GDD.md)
- Visual design: [docs/DESIGN.md](docs/DESIGN.md)
- 3D assets and licences: [docs/ASSETS.md](docs/ASSETS.md)

Status: early development. The APK builds in GitHub Actions on every push to `main`.
